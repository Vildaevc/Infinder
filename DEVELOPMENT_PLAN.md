## 0. Текущее состояние и workflow

**Workflow разработки (как сейчас):**

```
правки в src/  →  npm run build  →  dist/infinder.user.js  →  перенос в TamperMonkey  →  ручное тестирование
```

**Целевой workflow (рекомендуется):**

```
правки в src/  →  npm run dev (dev-сервер)  →  @require локального URL в TamperMonkey  →  авто-перезагрузка
```

> `vite-plugin-monkey` при `npm run dev` отдаёт userscript по локальному URL, который можно подключить через `@require` в TamperMonkey. Это ускоряет цикл «изменил → проверил». Для финальной проверки — `npm run build`.

## Фаза 1 — Критичные исправления (блокеры)

Цель: починить то, что ломает базовый функционал.

### 1.1 Исправить обработчик кнопок категорий 🔴
- **Файл:** `src/main.js`
- **Что:** заменить `e.target` на `e.currentTarget` в цикле по `.isf-btn`.
- **Критерий приёмки:** клик по иконке/подписи кнопки запускает нужную категорию и подсвечивает именно кнопку.

### 1.2 Защитить восстановление позиции из `localStorage` 🟠
- **Файл:** `src/main.js`
- **Что:** обернуть `JSON.parse(localStorage.getItem("isf_pos_v3"))` в `try/catch` с фолбэком на `{ right: 20, bottom: 20 }`.
- **Критерий приёмки:** при повреждённом/недоступном `localStorage` виджет всё равно появляется.

### 1.3 Починить дедупликацию inline-SVG 🟠
- **Файл:** `src/search/svg.js`
- **Что:** ключ уникальности — хеш от `outerHTML` (или полная сериализованная строка), а не `innerHTML.length`.
- **Критерий приёмки:** разные SVG с одинаковой длиной строки не отбрасываются; пустые `<svg>` не схлопываются в один.

### 1.4 Разделить «найдено» и «отображено» для картинок 🟠
- **Файл:** `src/search/images.js`
- **Что:** считать `e.size` по фактически добавленным плиткам; при `onerror` рисовать placeholder (или не добавлять в `foundUrls`).
- **Критерий приёмки:** статус «Найдено: N» совпадает с числом плиток; «Скачать все» не качает битые URL.

### 1.5 Поправить статус при ошибке 🟡
- **Файл:** `src/search/index.js`
- **Что:** в `finally` не показывать «Ничего не найдено», если было исключение (разделить ветки успеха/ошибки).
- **Критерий приёмки:** при ошибке показывается только «Ошибка поиска».

### 1.6 Поправить центрирование попапа 🟡
- **Файл:** `src/main.js` (и `src/config.js`)
- **Что:** вынести ширину попапа в конфиг и считать смещение как `popupWidth / 2`, а не магическое `210`.
- **Критерий приёмки:** окно центрируется точно.

## Фаза 2 — Унификация и надёжность скачивания

Цель: единый и предсказуемый механизм загрузки файлов.

### 2.1 Единая точка скачивания
- **Файлы:** `src/search/svg.js`, `src/search/fonts.js` (и общий хелпер, например `src/download.js`).
- **Что:** везде использовать `GM_download`, `saveAs` — только fallback. SVG/шрифты перевести с прямого `saveAs` на `GM_download`.
- **Критерий приёмки:** скачивание SVG и шрифтов не зависит от CDN FileSaver.

### 2.2 Явный тип записей в `state.foundUrls`
- **Что:** унифицировать формат (например, всегда `{ url, name }`) вместо смеси строк и объектов.
- **Критерий приёмки:** «Скачать все» работает без ветки `e.url || e`.

### 2.3 Fallback для CDN FileSaver
- **Что:** определить, нужен ли вообще `@require FileSaver` после 2.1; если да — оставить как fallback, иначе убрать.
- **Критерий приёмки:** при недоступном CDN функционал не падает.

## Фаза 3 — Безопасность и изоляция

### 3.1 Экранирование вставляемых значений
- **Файл:** `src/search/fonts.js`
- **Что:** экранировать `font-family` перед вставкой в `innerHTML` (или собирать DOM через `textContent`).
- **Критерий приёмки:** вредоносное имя шрифта не инжектит HTML.

### 3.2 Усиление изоляции стилей
- **Файл:** `src/styles.js`
- **Что:** расширить сброс наследования для потомков `#isf-root` (margin/padding, стилизация `button`/`svg`, `line-height` и т.п.).
- **Критерий приёмки:** виджет выглядит одинаково на сайтах с агрессивными глобальными стилями.

## Фаза 4 — Чистка и рефакторинг

### 4.1 Удалить мёртвый код
- `src/config.js`: убрать `primaryColor`.
- `src/state.js`: убрать неиспользуемый `state.drag` (или перенести туда состояние драга из `drag.js`).
- `src/search/index.js`: убрать бесполезную IIFE-обёртку.
- **Критерий приёмки:** сборка не содержит мёртвых символов; grep не находит неиспользуемые поля.

### 4.2 Вынести magic-числа в `config`
- Ширина попапа, z-index toast, смещения — в `src/config.js`.
- **Критерий приёмки:** нет разбросанных чисел в `main.js`/`styles.js`.

### 4.3 Согласовать версии
- Привести в соответствие `package.json` (`version`) и `vite.config.js` (`version` userscript).
- **Критерий приёмки:** версия указана в одном месте или синхронизирована.

## Фаза 5 — Производительность и UX

### 5.1 Оптимизация обхода DOM
- **Файлы:** `src/search/images.js`, `src/search/colors.js`
- **Что:** уменьшить число `getComputedStyle`-вызовов; обрабатывать только видимые/значимые элементы, рассмотреть батчинг.
- **Критерий приёмки:** на крупной странице поиск не «зависает» ощутимо.

### 5.2 Расширение парсера цветов
- **Что:** поддержка `hsl()`, именованных цветов, сохранение/отображение альфы.
- **Критерий приёмки:** корректно распознаются и копируются цвета в разных форматах.

### 5.3 Состояние загрузки и пустые состояния
- **Что:** лоадер при поиске, явные пустые состояния на категорию, placeholder для битых картинок.
- **Критерий приёмки:** понятная обратная связь при любом результате.

## Чек-лист ручного тестирования (после каждой правки)

1. Плагин подключается, кнопка появляется.
2. Перетаскивание кнопки работает, позиция сохраняется после перезагрузки.
3. Попап открывается/закрывается, drag за заголовок работает.
4. Все 5 категорий запускаются кликом **по иконке и по подписи** (после Фазы 1.1).
5. «Скачать все» скачивает корректные файлы (картинки, SVG, шрифты).
6. Копирование цвета в буфер показывает toast.
7. Проверка на «тяжёлой» странице (много DOM-элементов).
8. Проверка на сайте с агрессивными глобальными стилями.
9. Проверка с отключённым/повреждённым `localStorage`.
