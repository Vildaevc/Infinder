# Infinder — userscript для поиска медиа на любой странице

**Infinder** — расширение для браузеров (userscript, работает в Tampermonkey / Violentmonkey), которое встраивает на любую страницу плавающий виджет-«лупу» и помогает находить и скачивать медиа-ресурсы сайта.

## Возможности

| Категория | Что находит |
|---|---|
| **Картинки** | Все `<img>` (включая `srcset`) и фоновые изображения (`background-image`, в т.ч. многослойные). Плитки **отсортированы по разрешению** (от больших к меньшим); битые картинки показаны заглушкой |
| **SVG** | Inline-`<svg>` (без дублей — по полной сериализации) и внешние `img[src$=".svg"]` |
| **Цвета** | Цвета страницы из `color`/`backgroundColor`, сгруппированы по частоте; поддерживаются все форматы (rgb/rgba/hsl/имена), у полупрозрачных сохраняется альфа (`#rrggbbaa`); клик — копирование HEX в буфер |
| **Шрифты** | `@font-face` из таблиц стилей страницы, с превью и скачиванием файла шрифта |
| **Медиа** | `<video>/<audio>/<source>` и ссылки на `mp4/webm/mp3/wav/mov/avi/mkv/pdf/zip/rar` |

Дополнительно:

- **Клик по элементу результата** — быстрая загрузка в папку браузера;
- **Кнопка с дискетой** на каждом элементе — системный диалог **«Сохранить как...»**;
- **«Скачать все»** — пакетное скачивание всех найденных файлов (с задержкой 0.5 с между файлами);
- плавающая кнопка и окно перетаскиваются; позиция кнопки запоминается;
- тёмная glassmorphism-тема, полностью изолированная от стилей сайта;
- защита от сбоев `localStorage`, надёжное скачивание без внешних CDN (`GM_download`).

## Установка

### Вариант 1. Готовая сборка

1. Соберите проект (см. ниже) или возьмите файл `dist/infinder.user.js`.
2. В Tampermonkey: **Utilities → Import from file** (или создайте новый скрипт и вставьте содержимое файла).
3. Скрипт активен на всех сайтах (`*://*/*`) — на странице появится круглая кнопка-лупа.

### Вариант 2. Режим разработки (авто-перезагрузка)

1. `npm install` и `npm run dev` — Vite запустит dev-сервер `vite-plugin-monkey`;
2. В Tampermonkey добавьте новый скрипт с `@require http://localhost:3000/infinder.user.js` (точный URL выводит dev-сервер);
3. Правки в `src/` подхватываются автоматически.

## Сборка и команды

```bash
npm install     # установка dev-зависимостей (vite, vite-plugin-monkey)
npm run dev     # dev-сервер (vite-plugin-monkey)
npm run build   # production-сборка -> dist/infinder.user.js
npm run check   # смоук-тест: сборка + проверка метаданных userscript
npm test        # то же, что check
```

Требования: Node.js ≥ 20, современный браузер (Chrome/Edge/Firefox).

## Структура проекта

```
src/
├── main.js               # Точка входа: создание виджета, restore позиции, обработчики
├── config.js             # Конфигурация: размеры, z-index, ширина попапа, цвета
├── state.js              # Общее состояние: isSearching, foundUrls (Set из {url, name})
├── utils.js              # resolveUrl(), getFileName()
├── download.js           # downloadFile() — GM_download с фолбэком; createSaveAsButton()
├── scan.js               # Пошаговый обход элементов страницы (для «тяжёлых» парсеров)
├── dom.js                # createWidget(): DOM виджета + инжект стилей
├── drag.js               # makeDraggable(): перетаскивание кнопки и попапа
├── styles.js             # CSS (тёмная glassmorphism-тема, изоляция под #isf-root)
└── search/
    ├── index.js          # searchDispatcher(): диспетчер, «Скачать все», состояния
    ├── images.js         # searchImages() — картинки, сортировка по разрешению
    ├── svg.js            # searchSvg()
    ├── colors.js         # searchColors()
    ├── fonts.js          # searchFonts()
    └── media.js          # searchMedia()
```

Сборка — единый файл `dist/infinder.user.js`. **Версия** скрипта берётся из `package.json` (единый источник).

## Как это работает

1. `main.js` создаёт виджет через `createWidget()` и вешает обработчики.
2. Клик по кнопке категории → `searchDispatcher(action)`.
3. Диспетчер показывает спиннер, очищает результаты и вызывает нужный парсер.
4. Парсер находит ресурсы и добавляет записи `{url, name}` в `state.foundUrls`, а в DOM — плитки/строки.
5. Клик по элементу скачивает файл (`downloadFile`); «Скачать все» — все записи с задержкой.

Скачивание унифицировано в `src/download.js`: сначала `GM_download` (не зависит от CORS/CDN), при недоступности — `<a download>`. Внешних зависимостей у скрипта нет.
