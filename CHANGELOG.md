# Changelog

Все заметные изменения проекта. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по [SemVer](https://semver.org/lang/ru/).

## [2.7.0] — 2026

Первый публичный релиз на GitHub: полностью переработанная версия 2.x (исходный монолитный скрипт перемещён в `archive/legacy_script.js`).

### Добавлено

- **«Сохранить как...»** — кнопка с дискетой на каждом элементе результата открывает системный диалог сохранения (клик по элементу — быстрая загрузка в папку браузера).
- **Перетаскивание на тач-экранах**: drag переведён на Pointer Events (мышь, палец, стилус) с `touch-action: none`.
- **Сортировка картинок по разрешению** (W×H, от больших к меньшим), прогрессивно по мере загрузки.
- **Ленивая загрузка превью картинок**: декодированные изображения держат только видимые плитки — экономия памяти на галереях с сотнями картинок.
- **Заглушки для не загрузившихся картинок** (в счётчик и «Скачать все» не попадают).
- **Спиннер поиска** и пустые состояния по категориям («Картинки не найдены» и т.п.).
- **Поддержка всех форматов цветов** (`rgb/rgba/hsl/имена`, нормализация через canvas) с сохранением альфы (`#rrggbbaa`).
- **Авто-обновление** userscript (`@updateURL`/`@downloadURL` на ветку `main`), метаданные автора и лицензии MIT.
- Документация: `README.md`, `AGENTS.md`, `CHANGELOG.md`; смоук-тест `npm run check`; **ESLint** (`npm run lint`, включая проверку контрактов проекта); GitHub Actions (CI и релиз по тегу).

### Исправлено

- Клик по иконке/подписи кнопки категории не запускал поиск (`e.target` → `e.currentTarget`).
- Падение виджета при недоступном/повреждённом `localStorage` (чтение и запись в `try/catch`).
- SVG: дубли определялись по длине строки — теперь по полной сериализации; иконки самого виджета больше не попадают в результаты; регистр расширения `.svg`/`.SVG` не важен, SVG с параметрами (`icon.svg?v=2`) не дублируется в «Картинках».
- Медиа-ссылки с query-строкой (`video.mp4?token=…`, `file.zip?dl=1`) не находились — расширение теперь определяется по пути; `blob:`-потоки плееров (MSE) в список не попадают.
- Счётчик «Найдено» не совпадал с числом плиток; «Скачать все» качал битые URL.
- «Ничего не найдено» больше не перекрывает «Ошибка поиска».
- Неточное центрирование окна (magic-число → расчёт по фактическим размерам).
- XSS через `font-family` и имена файлов (сборка DOM через `textContent`/CSSOM).
- Копирование цвета: понятная обратная связь, если буфер обмена недоступен.
- data:-картинки скачивались как файл без расширения — имя берётся из MIME (`image.png`).
- Стили сайта просачивались в виджет — CSS изолирован под `#isf-root`.
- Тяжёлые страницы «зависали» при поиске картинок/цветов — пошаговый обход DOM (`src/scan.js`).

### Изменено

- Скачивание унифицировано (`src/download.js`): везде `GM_download`, внешний CDN FileSaver удалён (его недоступность ломала весь скрипт); добавлен фолбэк для менеджеров без `GM_download` (OrangeMonkey).
- `state.foundUrls` хранит единый формат `{ url, name }`.
- Версия userscript берётся из `package.json`; magic-числа вынесены в `config.js`.
- Удалены мёртвый код (`primaryColor`, `state.drag`, IIFE-обёртки) и кнопка «Свернуть» (работала неочевидно).
- Медиа-строки скачивают файл (раньше открывали новую вкладку).
