# AGENTS.md — правила работы с репозиторием Infinder

Файл описывает конвенции проекта. Он рассчитан и на людей, и на ИИ-агентов (Codex, Claude Code, DSH и др.), которые вносят правки в код.

## Что это за проект

**Infinder** — userscript для поиска и скачивания медиа на любой странице (картинки, SVG, цвета, шрифты, медиа). Собирается Vite + `vite-plugin-monkey` в единый файл `dist/infinder.user.js`. Runtime-зависимостей нет.

- Автор: Vildaevc — https://github.com/Vildaevc
- Лицензия: MIT
- Версия — **единственный источник: `package.json`** (в метаданные userscript попадает через `vite.config.js`).

## Команды

```bash
npm install       # зависимости
npm run dev       # dev-сервер (vite-plugin-monkey)
npm run lint      # ESLint + проверка контрактов проекта
npm run build     # сборка dist/infinder.user.js
npm run check     # смоук-тест: сборка + проверка метаданных (он же npm test)
```

**Правило сборки:** `dist/infinder.user.js` **коммитится** в репозиторий (на него ссылается инструкция «просто использовать» и `@updateURL`). Любая правка в `src/` обязана сопровождаться `npm run build` перед коммитом. CI (`npm run check` + `git diff --exit-code -- dist`) падает, если сборка не соответствует исходникам.

## Карта кода

| Файл | Ответственность |
|---|---|
| `src/main.js` | Точка входа: создание виджета, позиция кнопки, обработчики кликов |
| `src/config.js` | Все числовые/цветовые константы виджета (magic-числа только здесь) |
| `src/state.js` | Общее состояние: `isSearching`, `foundUrls` |
| `src/i18n.js` | Локализация интерфейса: `t()`, английский — база, русский — для `ru`-локали |
| `src/download.js` | `downloadFile()` — единственная точка скачивания; `createSaveAsButton()` |
| `src/scan.js` | Пошаговый обход DOM (`scanPageElements`) для тяжёлых парсеров |
| `src/dom.js` | Разметка виджета + инжект стилей |
| `src/drag.js` | Перетаскивание кнопки/окна |
| `src/styles.js` | CSS темы; все селекторы ограничены `#isf-root` |
| `src/search/index.js` | `searchDispatcher()`: лоадер, вызов парсера, «Скачать все», пустые состояния |
| `src/search/<категория>.js` | Парсеры: `images`, `svg`, `colors`, `fonts`, `media` |
| `scripts/check-build.mjs` | Смоук-тест сборки и метаданных |

## Контракты, которые нельзя ломать

1. **Скачивание — только через `downloadFile(url, name, saveAsDialog)`** из `src/download.js`. Не вызывайте `GM_download`/`fetch`/`window.open` напрямую для скачивания.
2. **Формат результатов:** `state.foundUrls` хранит **только** объекты `{ url, name }`. Диспетчер и «Скачать все» не должны содержать веток вида `item.url || item`.
3. **Парсер** — `async function`, возвращает **число реально добавленных элементов**. Битые/недоступные ресурсы в `foundUrls` и в счётчик не попадают (для них рисуется заглушка).
4. **Данные страницы — недоверенные.** Никакого `innerHTML` с URL/именами/значениями CSS: только `textContent`, `document.createElement`, CSSOM (`el.style.setProperty`). Статические иконки/шаблоны через `innerHTML` допустимы.
5. **Не сканировать собственный виджет:** тяжёлые парсеры идут через `scanPageElements` (он исключает `#isf-root`), а точечные выборки (`svg`, `img`) обязаны пропускать элементы внутри `#isf-root`.
6. **Изоляция стилей:** каждый новый селектор — с префиксом `#isf-root`; отступы/размеры, критичные для вида, — с `!important` (глобальный сброс хоста сильнее обычных правил).
7. **Magic-числа** (размеры, z-index, отступы-константы) — в `src/config.js`.
8. **Внешние зависимости** не добавляются: ни npm-пакетов в рантайме, ни `@require` с CDN (падение CDN ломает весь скрипт). В `devDependencies` допустимы только сборка и проверки: `vite`, `vite-plugin-monkey`, `eslint`, `@eslint/js`.
9. **Пользовательские строки — только через `t()`** из `src/i18n.js`: базовый язык английский, русский включается автоматически для `ru`-локали браузера. Никаких «зашитых» подписей, статусов, тостов и `title` — включая кириллицу в строковых литералах вне `src/i18n.js` (это проверяет линтер).

Дополнительно линтер (`npm run lint`, конфиг `eslint.config.mjs`) запрещает: `querySelectorAll("*")` (используйте `scanPageElements`), прямые вызовы `saveAs()` и `GM_download()` вне `src/download.js`, а также кириллические строковые литералы вне `src/i18n.js`.

Осознанные решения (не «улучшать» без запроса):

- **Код не минифицируется** — бандл ~53 КБ, зато читаемый: проще ревьюить, проверять и проходить модерацию.
- **Стиль — ES2019-совместимый** (`var`, `function`), без TypeScript и новомодного синтаксиса.
- **Цвета выводятся как есть** (близкие оттенки с разной альфой — отдельные чипы).

## Стиль кода

- ES-модули (`import`/`export`), сборка — Vite; синтаксис ES2019-совместимый (`var`, `function`), без TypeScript и без транспиляции новых фич.
- Комментарии — **на русском**, короткие и по делу (объясняют «почему», а не «что»).
- Имена переменных — осмысленные (`url`, `name`, `tile`), никаких `e/i/r/o/n/s` в новом коде.
- Файлы: `kebab`/`camel` как в существующих; один модуль — одна ответственность.
- Никаких новых зависимостей и инструментов без обсуждения.

## Как проверить правку

1. `npm run lint` — должно быть 0 ошибок (включая контракты проекта).
2. `npm run check` — должно быть зелёно (сборка + метаданные).
3. Прогнать затронутый сценарий руками: установить `dist/infinder.user.js` в TamperMonkey/OrangeMonkey и пройти чек-лист ниже.
4. Для UI-правок проверить сайт с агрессивными глобальными стилями (reset.css, стилизация `button`/`svg`).

### Чек-лист ручного тестирования

1. Виджет появляется; попап открывается, центрирован, перетаскивается (мышью и пальцем), позиция кнопки сохраняется после перезагрузки.
2. Все 5 категорий запускаются кликом и по иконке, и по подписи; активная кнопка подсвечивается.
3. Картинки: «Найдено: N» совпадает с числом плиток, сортировка по разрешению, битые — заглушками, «Скачать все» их не качает.
4. SVG / Шрифты / Медиа: находятся и скачиваются (клик — быстрая загрузка, дискета — «Сохранить как...»).
5. Цвета: копирование в буфер с тостом; полупрозрачные — в формате `#rrggbbaa`.
6. Тяжёлая страница: поиск не подвешивает UI (спиннер, постраничный обход DOM).
7. Сайт с агрессивными глобальными стилями: виджет выглядит одинаково.
8. Отключённый или повреждённый `localStorage`: виджет всё равно появляется.
9. Менеджер без `GM_download` (OrangeMonkey): скачивание работает через фолбэк.
